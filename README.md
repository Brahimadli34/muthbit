# مُثبِت

أداة للتحقق من الأحاديث والآيات والأقوال المنسوبة في المنشورات المتداولة. يلصق المستخدم المنشور كما وصله، فتستخرج الأداة كل نص منسوب فيه، وتطابقه مع مصادر معتمدة، وتعرض لفظه الأصلي ومصدره وحكمه كما نقله أهل الاختصاص، أو تمتنع وتحيل إلى مختص عند غياب المرجع.

المسار: أدوات المعرفة والتحقق لتمكين المعرفين بالإسلام، ضمن تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي.

## مبدأ الموثوقية

النموذج اللغوي لا يُصدر الحكم على أي نص. دوره الوحيد استخراج النصوص من المنشور، وكل نص يستخرجه يُتحقق من وجوده حرفياً في المنشور الأصلي، وإلا حُذف. أما الحكم والمصدر فيُنقلان من قاعدة البيانات كما هما، بقرار حتمي في `backend/verifier/verdict.py`:

| الحالة | المخرج |
|---|---|
| التشابه أقل من عتبة المطابقة | امتناع وإحالة إلى مختص |
| للسجل أحكام متعارضة | عرض الأحكام كلها دون ترجيح |
| موضوع أو لا أصل له | بيان الوضع مع المصدر والحكم |
| ضعيف | تضعيف مع المصدر والحكم |
| قول ثابت منسوب لغير قائله | بيان النسبة الصحيحة |
| الأحكام المنقولة على الإسناد فقط | عرض الحكم على الإسناد دون المتن |
| مروي في كتاب غير الصحيحين ولا حكم مُراجَعاً عليه | عزو إلى المصدر دون حكم |
| صحيح أو حسن أو قرآن، تشابه عالٍ | تأكيد مع المصدر والحكم |
| صحيح أو حسن أو قرآن، تشابه متوسط | تأكيد مع بيان الاختلاف عن اللفظ الأصلي |

الاختبارات تتحقق من أن الضعيف والموضوع لا يُؤكَّدان أبداً مهما بلغ التشابه.

## الكتب التسعة

```bash
python manage.py import_nine_books ../data/nine_books.xlsx --replace-books --license "[الترخيص]"
python manage.py build_index
```

- اسم الكتاب من `BookID`، والمتن من `Matn`، والرقم من علامة الحديث في `hadithTxt` ولو سبقها عنوان الباب. أي الرقمين هو الترقيم المشهور محدد لكل كتاب في `NUMBER_POSITION` (البخاري والترمذي والنسائي وابن ماجه: الثاني؛ مسلم وأبو داود وأحمد: الأول). مالك والدارمي يحتاجان تحققاً.
- عند تكرار النص في عدة كتب بالدرجة نفسها تقريباً، يُقدَّم الصحيحان، ويُكشف «المتفق عليه» إن تطابق المتن في الكتابين.
- أحاديث `--sahih-books` (الافتراضي: البخاري ومسلم) تُصنّف صحيحة، ويُكشف «المتفق عليه» تلقائياً.
- ما سواها «مروي دون حكم»: يُعزى إلى موضعه من القاعدة المحلية، ويُطلب حكمه من الدرر. إن لم يوجد حكم مُراجَع، يكون المخرج «عزو إلى المصدر دون حكم»، ولا يُؤكَّد أبداً.
- على القاعدة كاملة (63,530 رواية): الاستيراد نحو 25 ثانية، والفهرسة نحو 15 ثانية، والفهرس نحو 230 ميجا، والاستعلام نحو ثلث ثانية.

## وضع المتخصص: الأسانيد ودرجات الرواة

مفتاح «وضع المتخصص» أعلى الصفحة يضيف إلى كل حديث من الكتب التسعة زر «الأسانيد ودرجات الرواة»، ويعرض:
- النص بإسناده كما في الكتاب.
- **الطرق:** كل إسناد للحديث في موضعه وفي مواضع التخريج، مقروءاً من صاحب الكتاب إلى الصحابي، وكل راوٍ ملوّن بدرجته (ثقة، صدوق، ضعيف، غير مصنّف) مع ترجمته عند الضغط، وتنبيه على الرواة الضعفاء في كل طريق. وتظهر المتابعات التي بلا متن مستقل.
- **شجرة الإسناد:** تدمج الطرق كلها من الصحابي، وتتفرّع حيث تختلف، وتبيّن مدار أكثر الطرق.

التلوين تقريبي من نص الدرجة، للتوجيه فقط، ولا يدخل في أي حكم تصدره الأداة.

```bash
python manage.py import_nine_books ..\data\nine_books.xlsx --replace-books   # يحفظ الأسانيد ومعرّفات hadithID
python manage.py import_isnad_data --narrators ..\data\narrators.xlsx --takhreeg ..\data\takhreeg.xlsx
python manage.py build_index
```

منطق الأسانيد والشجرة مأخوذ من تطبيق «موسوعة الحديث الشريف - الكتب التسعة» لصاحب المشروع.

## القرآن الكريم

نزّل نص المصحف من [Tanzil](https://tanzil.net/download) بصيغة «Text (with aya numbers)»، ثم:

```bash
python manage.py import_quran ..\data\quran-uthmani.txt
python manage.py build_index
```

النصوص المنسوبة إلى القرآن لا تُبحث في موسوعة الحديث، لأن نتائجها أحاديث تتضمن الآية لا الآية نفسها.

## مصادر البحث: طبقتان

1. **القاعدة المحلية:** نصوص يراجعها المختص (القرآن، وأشهر المتداول المكذوب...). سريعة، وتعمل دون إنترنت.
2. **الدرر السنية:** عبر [خدمة الموسوعة الحديثية](https://dorar.net/article/389)، حين لا تكفي القاعدة المحلية. يُعاد قياس تشابه كل نتيجة مع النص المتداول، وتُعامل الروايات المتقاربة على أنها النص نفسه بأحكام محدّثين مختلفين، فإن اختلفت أحكامهم عُرضت كلها دون ترجيح.

**جدول تحويل الأحكام** (`data/grade_map_suggested.csv`، ويُدار من `/admin`): يحوّل عبارة الحكم كما وردت في الدرر إلى تصنيف الأداة. الجدول المرفق **مقترح يراجعه المختص**، ولا تستعمل الأداة إلا العبارات المعلَّمة «تمت مراجعته». أي عبارة غير مصنّفة تؤدي إلى الامتناع، لا إلى التخمين.

```bash
python manage.py import_grade_map ../data/grade_map_suggested.csv --replace
```

ثم راجع كل عبارة من `/admin` وعلّمها «تمت مراجعته».

لمعرفة العبارات التي وردت فعلاً من الدرر ولم تُصنّف بعد، مرتبة حسب الشيوع:

```bash
python manage.py grade_phrases --csv phrases.csv
```

## المحدّثون المعتمدون

من `/admin` ← «المحدّثون المعتمدون» (مُعدّ مسبقاً: الألباني، أحمد شاكر، شعيب الأرناؤوط). إن صحّح الحديثَ أو حسّنه أحدُهم ولم يخالفه معتمد آخر، تكون النتيجة تأكيداً مع خلاصة مثل «صحّحه الألباني». وإن اتفقوا على التضعيف فتضعيف، وإن اختلفوا فتعارض بخلاصة الطرفين: «ضعّفه الألباني، وحسّنه شعيب الأرناؤوط». والحكم على الإسناد وحده لا يُعدّ تصحيحاً. أحكام غيرهم تبقى معروضة كاملة.

## النماذج اللغوية

تُضاف من `/admin` ← «نماذج الذكاء الاصطناعي» دون تعديل الكود. نمطان مدعومان:

- **متوافق مع OpenAI:** OpenAI، DeepSeek، Groq، Mistral، Gemini (الرابط `https://generativelanguage.googleapis.com/v1beta/openai/`)...
- **Anthropic:** Claude، ويُترك الرابط فارغاً.

يُجرَّب المفعّل منها لاستخراج النصوص حسب الأولوية، فإن فشل انتقل إلى التالي، ثم إلى الاستخراج القاعدي. والمعلَّم «نموذجاً مرجعياً» يُقارن به في سكربت التقييم. زر «اختبار الاتصال» في قائمة الإجراءات يتحقق من الإعداد.

**المفتاح:** الأفضل وضعه في متغير بيئة وكتابة اسمه في حقل «اسم متغير البيئة». إن خزّنته في قاعدة البيانات فهو نص صريح، فاحصر الوصول إلى `/admin`. المفتاح لا يُعرض بعد حفظه.

## البنية

```
backend/    Django + DRF
  verifier/arabic.py      تطبيع النص العربي ونسبة الاحتواء
  verifier/retrieval.py   بحث لفظي (TF-IDF على مقاطع الحروف) + دلالي اختياري
  verifier/extraction.py  استخراج النصوص (نموذج لغوي مع تحقق، أو قواعد عند غيابه)
  verifier/verdict.py     منطق الحكم (دالة نقية)
  verifier/dorar.py       عميل الدرر ومحلل النتائج وتحويل الأحكام
  verifier/llm_client.py  عميل موحّد للنماذج (OpenAI-compatible / Anthropic)
  verifier/services.py    ربط المراحل
frontend/   React + Vite
eval/       سكربت التقييم والمقارنة بنموذج عام
data/       قالب المصادر وعينة للتجربة
```

## التشغيل المحلي

```bash
# الخلفية
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py import_sources ../data/sample_sources.csv --replace
python manage.py build_index
python manage.py import_grade_map ../data/grade_map_suggested.csv --replace
python manage.py createsuperuser
python manage.py test verifier
python manage.py runserver 127.0.0.1:8000

# الواجهة (نافذة أخرى)
cd frontend
npm install
npm run dev        # http://localhost:5173
```

لوحة مراجعة البلاغات والنصوص: `python manage.py createsuperuser` ثم `/admin`.

### متغيرات البيئة

| المتغير | الوظيفة | الافتراضي |
|---|---|---|
| `ANTHROPIC_API_KEY` | احتياط فقط إن لم يُضف أي نموذج من لوحة الإدارة | فارغ |
| `MUTHBIT_DORAR_ENABLED` | تفعيل البحث في الدرر | `1` |
| `MUTHBIT_DORAR_CACHE_HOURS` | مدة حفظ نتيجة الاستعلام | `168` |
| `MUTHBIT_GRADE_MAP_REVIEWED_ONLY` | استعمال العبارات المراجَعة فقط | `1` |
| `MUTHBIT_USE_EMBEDDINGS` | تفعيل البحث الدلالي (يتطلب `requirements-embeddings.txt`) | `0` |
| `MUTHBIT_EMBEDDING_MODEL` | نموذج التضمين | `intfloat/multilingual-e5-base` |
| `MUTHBIT_THRESHOLD_MATCH` | أدنى تشابه لاعتبار النص موجوداً | `0.55` |
| `MUTHBIT_THRESHOLD_EXACT` | أدنى تشابه لاعتبار اللفظ مطابقاً | `0.85` |

## بيانات المصادر

الصيغة في `data/sources_template.csv`. الحقول الإلزامية: `source_name`, `kind` (quran / hadith / athar), `text`, `grade_class` (quran / sahih / hasan / daif / mawdu / la_asl / misattributed).

`other_grades` نص JSON عند اختلاف المحدّثين:
`[{"grade": "حسن", "grader": "...", "ref": "..."}]`

العينة في `data/sample_sources.csv` للتجربة فقط، وتُستبدل بالمصادر المعتمدة بعد التحقق من تراخيصها وتوثيقها في `SOURCES.md`.

## التقييم

```bash
cd eval
pip install -r requirements.txt
python evaluate.py --xlsx muthbit_test_set.xlsx --api http://127.0.0.1:8000 \
    --baseline --repeats 3 --sweep --split --out reports
```

`--baseline` يقارن بكل نموذج معلَّم «نموذجاً مرجعياً» في لوحة الإدارة. أو حدّد نموذجاً من سطر الأوامر:
`--baseline-model gemini-3.1-flash-lite --baseline-base-url https://generativelanguage.googleapis.com/v1beta/openai/ --baseline-key-env GEMINI_API_KEY`

يُخرج `reports/report.md` بالمقاييس التالية لمُثبِت وللنموذج العام: مطابقة المخرج المتوقع، والأخطاء الحرجة (تأكيد ما لا يصح)، وصحة الإسناد، والمصادر المختلقة، ودقة الامتناع واستدعاؤه، وثبات المخرج عبر التكرارات، ونسبة استخراج النصوص من المنشورات المركبة. الخيار `--sweep --split` يضبط العتبات على نصف المجموعة ويقيس على النصف الآخر حتى لا تُبالغ النتيجة.

## النشر

- الخلفية: Render عبر `render.yaml` (يقرأ `data/sources.csv`).
- الواجهة: Netlify أو Cloudflare Pages، أمر البناء `npm run build`، مجلد النشر `frontend/dist`، مع `VITE_API_URL` = رابط الخلفية.
- الخطة المجانية على Render تتوقف عند الخمول، فافتح الرابط قبل جلسة التحكيم.

## الحدود المعروفة

- الأداة لا تحكم إلا بما في قاعدة مصادرها، فالامتناع يعني غياب المرجع لديها لا بطلان النص.
- جودة المطابقة للمروي بالمعنى تتحسن كثيراً بتفعيل البحث الدلالي.
- الأسئلة الفقهية والفتوى خارج نطاق الأداة.

## الإفصاح

انظر `DISCLOSURE.md` لنسخة البداية، و`SOURCES.md` لسجل المصادر والأدوات والتراخيص.
